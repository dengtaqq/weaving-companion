# 图片创作

## 目标

把用户的视觉需求转成可审核的图片产物。图片服务尚未配置时，完成可用的创作说明并准确告知能力状态，不假装已经出图。

## 执行

1. 明确图片用途、尺寸或比例、主体、风格、文案、参考材料和必须保留的元素。涉及商家时遵守当前商家的已确认资料与表达限制。
   编写本次提示词时使用 [图片提示词组装](references/image-prompt.md)；任务是小红书封面时再读取 [小红书封面提示词](references/xhs-cover-prompt.md)。两份规则按本轮内容组装提示词，不把示例当成固定文案。
2. 检查本轮是否装配图片工具、所选能力是否支持文生图、参考图改图或画布区域改图。参考图必须是当前任务可访问且已登记的文件；画布圈选以实际保存的区域引用为准。
3. 实际生成前遵守产品的费用与确认流程。请求应绑定输入引用和稳定请求键；超时或结果未知时先查询原请求状态，不盲目重复付费。
4. 工具成功后核对返回的图片、尺寸与产物登记状态。仅当文件完整且可访问时称为已生成；用户要求修改时保留原版本并生成新版本。

## 交付

提供图片产物引用、用途和需要用户审核的内容。尚无图片能力、费用未确认、生成失败或结果待对账时，明确当前状态；可以交付本次视觉提示词与方案，但不能把它们说成图片产物。
