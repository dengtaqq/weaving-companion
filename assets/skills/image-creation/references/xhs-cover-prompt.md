# 小红书封面提示词

仅在本轮需要小红书封面时读取。封面需要让读者快速看出笔记主题，同时与正文事实、当前商家的表达边界一致。先按 [图片提示词组装](image-prompt.md) 确定通用输入，再补封面特有的判断。

## 从笔记确定封面

1. 读取当前版本的标题、正文要点、目标读者、核心信息和用户指定的封面文字。缺少正文时，可用用户明确提供的提纲；只有主页链接时不能推断笔记内容。
2. 从当前任务可访问、已实际查看的案例中提取有用的视觉特征，例如布局、信息层级、色调和拍摄方式。若案例带有 `reference_prompt`，把其中适合本轮内容的特征改写进提示词；不要照搬案例中的商家、商品、标题或未经核实的效果。没有案例时直接依据笔记和商家资料组装，不虚构“案例库命中”。
3. 根据内容选封面形式：真实素材能准确表达主题时优先使用；示意、拼贴或生成画面要与事实图明确区分。人物、门店和商品若需要呈现为真实记录，必须有可使用的真实素材。
4. 封面文字提炼一个可读的重点，可与笔记标题换角度表达，但不能改变承诺或新增事实。用户明确指定原文时尊重原文；字数、位置和留白以可读性为准。

## 本次提示词应写清

- 笔记主题、目标读者、封面要突出的信息；
- 画面主体、封面形式、构图和与文字相配的留白；
- 本轮有依据的风格、色彩与场景约束；
- 需要出现在画面上的准确文字，以及不能出现的无据价格、功效、评价等；
- 参考素材或案例所起的具体作用，哪些真实元素必须保留。

画幅按用户要求或实际交付规格确定；项目尚未固化封面尺寸时，不把某个像素值写成全局规则。若图片工具不能可靠生成文字，可先交付封面画面提示词和文字排版说明，待具备相应编辑能力时完成文字；不能把无字底图称为已完成的封面。

## 出图后的核对

实际查看生成结果，核对画面文字是否准确、信息是否一眼可读、主体是否贴合笔记、真实与示意是否易混淆、比例与商家限制是否满足。仅有提示词、文件名或工具回执时，不作“封面已审核通过”的判断。
