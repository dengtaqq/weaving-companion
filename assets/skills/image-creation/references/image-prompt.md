# 图片提示词组装

当任务需要文生图或参考图改图时，用当前任务资料编写一次性提示词。这里定义写法，不预设某个商家的画面，也不指定图片服务或工具参数名称。

## 取材

- 先确定图片用途、投放位置和用户明确要求；从当前商家已确认档案、当前稿件及本轮可访问素材中提取可用事实。
- 把参考图的作用说清楚：是保留主体、借鉴构图、借鉴色彩，还是只用于识别商品。链接、文件名和案例描述不能代替实际查看图片。
- 缺少商品外观、门店环境等关键依据时，用示意画面或明确的待补素材说明，不能编造真实经营场景。

## 组装

把以下信息写成一条清楚的自然语言提示词，按实际需要取舍：

1. **用途与主体**：这张图给谁看、传达什么；主体是什么、正在做什么。
2. **场景与构图**：场景、镜头视角、主体位置、留白和画幅。比例或尺寸依据用户要求及明确的交付规格确定；没有可靠依据时先确认。
3. **视觉语言**：适合当前商家和内容的媒介、色彩、光线与质感。没有来源的品牌风格不要自行设定。
4. **画面文字**：只写已确认的原文，并指出层级和大致位置；价格、优惠、效果承诺必须有可靠依据。
5. **保留与避免**：改图时分别写明必须保留的主体、标识、构图等，以及要修改或避免的元素。不要承诺局部以外像素完全不变。

如果图片工具提供结构化字段，可把风格、场景、构图、光线、保留项和画面文字分别放入对应字段；否则合并为同一条提示词。工具字段、模型、输出路径和费用规则以本轮实际能力为准，不从示例推断。

## 可填写骨架

> 用于【用途】的【画幅】图片，面向【受众】。主体为【可核实的主体】，呈现【动作或卖点】；场景【场景】，构图【主体位置与留白】；采用【风格、色彩、光线】。画面文字为“【已确认原文】”，放在【位置与层级】。参考【已查看的素材】用于【具体借鉴或保留范围】。必须保留【元素】，避免【元素】。

按本轮任务删去不适用的字段，不把方括号内容原样提交给图片工具。提示词完成后区分“已核实输入”“创作选择”和“待确认项”；没有真实生成回执时只称为提示词草案。
