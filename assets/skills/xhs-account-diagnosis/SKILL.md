# 小红书账号诊断

## 目标

在证据允许的范围内判断账号定位、现有素材的问题和可改进方向。诊断是独立的业务能力，可与选题规划相衔接，但不要求每次创作都先诊断；不凭公开主页推断订单、转化和总体经营结果。

## 输入

1. 确认目标账号标识、诊断时间范围和可用证据；已关联商家时再核对账号与该商家的关系。用户给公开主页时先使用 `xhs-public-evidence-collection`，读取实际采集状态与证据 ID。
2. 已授权账号数据与公开页面观察分开保存。前者可用于已提供口径的内容和表现分析；后者只支持页面实际可见的判断。未查询或不可见的指标明确标缺失。
3. 已关联商家时读取其已确认的档案、商品库、目标人群和经营目标；具体商品调用 `merchant_catalog_get` 核对冻结版本。未关联时将这些资料列为缺口，不能用账号昵称、单篇笔记或模型猜测替代事实。

## 分析与输出

- 给出诊断范围、证据时间、账号定位与目标人群匹配情况、可见内容主题、标题/封面/正文等素材问题，以及已核实的表现信息。
- 每个主要判断对应具体证据；资料较少时只给有限观察，不假装完成历史趋势或矩阵分析。
- 建议说明可尝试的内容方向、预期目标、需要补充的资料和验证指标。不自动创建选题计划、图片或发布任务。
- 已取得当前会话可读证据、用户要求形成诊断时，用 `account_diagnosis_save` 保存公开资料诊断草稿；未关联商家时草稿先归当前会话。每条观察和建议引用本轮实际读取的证据 ID，未知项单列。保存后按返回的诊断 ID 和 `DRAFT` 状态交付，不称为完整经营诊断。
- 商家页可由用户选择一版来源完整的草稿，导出固定的公开资料 Markdown 报告。报告明示缺少经营数据；导出动作不把模型判断改成人工确认事实，也不等于完整经营诊断状态机已完成。
- 若页面登录受限、采集失败或缺少足够内容，不保存无依据的报告。用户提供的可读取材料可以用于标明范围的人工辅助分析，但不能称为自动主页诊断。
