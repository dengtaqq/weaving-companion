# 固定研究交付模板 v1

报告由 Host 从冻结商家资料与已保存的结构化结果生成，章节和字段不由模型临时决定。每轮成功研究合并本次执行尝试的候选批次，只形成一份报告；失败、取消或中断不形成成功报告。站点受限但任务成功交付缺口时，生成无候选的缺口报告。

固定为以下五部分：

1. 商家与研究范围：商家、档案版本、行业、服务区域、产品/服务、客群、目标、本次重点与以 Run 受理时间固定的观察窗口。
2. 结论与覆盖：候选数量、实际采样范围、商家选择理由及覆盖限制，来自已提交 coverage，不补写未经取证的概括。
3. 研究发现：依次包含关键词、近期话题、竞品内容差异。当前未研究的类别写“本次未开展此项研究”；当前研究无结果写明缺口。每项保留商家关联、客群、类别/意图/优先级或发布时间/比较维度、来源批次和证据 ID。
4. 后续内容方向与使用前提：使用候选原有 contentAngle 和 cautions，不另外编造选题卡、价格、活动、设施或承诺。
5. 证据与待补充事项：去重的证据链接、采集时间、gaps 及来源 Run/执行尝试/快照。发布时间与采集时间分别表达。

模型必须先保存候选或缺口，再结束回复。Host 自动报告以本次尝试的已保存候选为准；不写入的自由回复不会自动变成可复用结论。简短最终回复说明候选数、主要限制和固定报告入口即可。

研究报告标记“候选待采用”，不是人工确认事实或已审核正式内容产物。用户可复制或下载 Markdown；采用相应建议后，后续会话用 merchant_research_get(format=REPORT) 取得相同五段式的已采用简报。简报仅含本轮冻结的采用条目，可按 query/itemId 筛选及 offset/limit 分页；读取简报不能扩大到同批未采用候选。

无采用条目时简报明确写空结果；过时资料需复核，有效期按冻结条目显示，未开展研究不能说成已检查且没有发现机会。
